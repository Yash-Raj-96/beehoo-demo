# BeeHoo Vercel Interactive Demo

Static frontend demo adapted from BeeHoo Phase 28. No PHP, database, authentication, or payments. Admin changes persist only in this browser using localStorage. Images uploaded in the demo are stored locally in the browser, subject to storage limits.

## Deploy
1. Import this folder into a GitHub repository.
2. In Vercel, **Add New → Project → Import Git Repository**.
3. Framework preset: **Other**; root directory: repository root; build command: **none**; output directory: **.**.
4. Deploy.

To use actual PHP/MariaDB functionality, deploy the original BeeHoo project to a PHP-capable host with MySQL/MariaDB instead.
